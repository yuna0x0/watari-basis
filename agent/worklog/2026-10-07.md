# 2026-10-07

## Basis sync, Unity 6000.7

Synced the clone to upstream `developer` at eac8e38cc, which moves Basis from Unity 6000.5 to
6000.7.0b2. Ran the suite against it: 355 green, no compile errors.

- 39 upstream commits: the editor upgrade (URP 17.7, Addressables 4, Input System, Timeline and
  Animation Rigging at 6.7.0), a media player rewrite, graphics state prewarm for DX12 and
  Vulkan, and an IK spine rework.
- The packages Watari references: `BasisAvatar` gained non-serialized load visibility fields,
  `BasisBundleGenerated` gained graphics state payload fields. Jiggle physics, `HVR.Basis.Comms`
  and `BasisDebug` are unchanged. The avatar validator and `BasisTransformMapping` (twist lookup)
  are unchanged. The IK spine rework removed the spine bend distribution and the cervical solve;
  UpperChest stays optional (used when mapped, Chest otherwise) and the validator neither requires
  nor warns about it, so `RigReadiness` needs no change.
  The eye driver gained a guard for an unset head rotation; `EyeMaxLookAngle` is unchanged.
- Both Watari assemblies recompiled with the 6000.7 compiler and references: no warnings, no
  errors. No Watari file was rewritten by the upgrade or the run. The one material fixture uses
  the built-in Standard shader, so the URP material version upgrade does not reach it, and there
  are no texture imports.
- `package.json` keeps `"unity": "6000.5"`: it is a minimum and nothing used needs 6000.7.
- `versions.md` Basis row raised to eac8e38cc. No package change.

## Source versions

Checked every source in `versions.md` for a newer release.

- VRChat SDK 3.10.5, Modular Avatar 1.18.7, NDMF 1.14.8 and Dynamic Bone 1.3.4 are the newest
  releases. Modular Avatar 1.19.0-alpha.0 and NDMF 1.15.0-beta.0 are prereleases and were not
  checked.
- UniVRM 0.131.3: `VRM10SpringBoneJoint` serializes the same fields. The release clamps cone and
  hinge angles to 0..180 degrees and spherical yaw to 0..90 in the importer and the solver, and
  the importer now skips a `VRMC_springBone_limit` with an unknown spec version, zero or several
  limits, or on a leaf node. The mapper already clamps a cone to jiggle's 0..90 range and drops
  the tail joint, which `FastSpringBoneBuffer` never simulates. Two tests pin both against
  0.131.3. The Basis project's UniVRM checkout moved to v0.131.3.
- VRCFury 1.1431.0: `Runtime/` is identical to 1.1429.0. The changes are a shader parsing fix in
  `SpsPatcher` and a `matchAll` field on `UdonDiInjectField`, a world component.
- No reader or mapper change. `CheckedAgainst`, `versions.md` and the changelog raised to UniVRM
  0.131.3 and VRCFury 1.1431.0.
- Suite on Unity 6000.7.0b2 with UniVRM 0.131.3: 357 green, no compile errors.

## Unity 6000.7 hex blobs

Unity 6000.7 ends a hex-serialized primitive array with a type letter (`0f000000i`). Checked
whether any reader sees it: the only hex reader is `ParseHexInt32Blob`, for `eyelidsBlendshapes`
on the VRChat descriptor, which is a missing script in a Basis project. A 6000.7 re-save of
avatar content left that field byte for byte unchanged; the suffixed fields were Basis's own
`FaceVisemeMovement` and `BlinkViseme`, which `BasisAvatarWriter` sets on the component. The
parser already skips a tail shorter than one value. No code or test change; the trigger for a
test is recorded under "Checking a new SDK release" in `research/vrchat-serialized-formats.md`.
Suite on 6000.7 at eac8e38cc: 357 green, no compile errors.
